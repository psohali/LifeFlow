About LifeFlow

An academic Blood Bank Management System built for India to streamline voluntary donor registration, blood request tracking, and stock administration.

What Is LifeFlow?

LifeFlow is a web-based Blood Bank Management System tailored for Indian healthcare workflows. It provides a unified portal where Indian citizens can register as voluntary blood donors and families or hospital coordinators can raise blood requests using Indian mobile numbers, PIN codes, and state records.

All donor records, blood requests, and blood unit counts are stored in a relational MySQL database rather than static files.

Importance of Voluntary Blood Donation

Every day across India, patients undergoing surgery, accident trauma care, childbirth, thalassemia treatment, and oncology therapy require safe blood components. Blood cannot be manufactured artificially—only voluntary donors make safe transfusions possible.

Voluntary donation in India is completely non-remunerated (₹0 donor payment), and a single donation of one unit can help save up to three lives when separated into red cells, plasma, and platelets.

How LifeFlow Connects Donors & Requests

  • Donor Registration: Eligible individuals (aged 18–65) submit their blood group, +91 mobile number, and Indian residential address.
  • Blood Request Submission: Requesters enter patient details, required units, hospital name (such as AIIMS New Delhi or Apollo Chennai), and urgency level. New requests start as Pending.
  • Administrative Review: Authenticated blood bank administrators review requests, update status (Approved, Rejected, or Fulfilled), log remarks, and maintain accurate stock levels.

Purpose of This Project

LifeFlow is developed as a clean, practical second-year B.Tech CSE full-stack project demonstrating structured HTML, CSS, and JavaScript frontend development paired with a Node.js, Express.js, and MySQL backend.

Note: The stock counts shown on the Blood Availability page are sample demonstration quantities for educational evaluation and do not represent live Indian hospital stock.
